# 儿童算术练习小程序 PRD

## 1. 产品概述

一款面向学前至小学2年级儿童的算术练习工具，支持口算题和竖式题批量生成、Word文档导出打印。目标用户包括：家长（为孩子生成练习卷）、小学老师（制作课堂作业）、儿童（直接在程序内练习或打印练习）。

核心价值：一键生成标准化A4练习卷，支持Word导出打印，解决家长和老师手动出题费时费力的问题。

---

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|---------|---------|
| 家长 | 生成打印练习卷 | 使用全部功能 |
| 小学老师 | 制作作业 | 使用全部功能 |
| 儿童 | 练习或打印 | 预览和练习 |

### 2.2 功能模块

1. **首页**：版本选择 + 知识点折叠列表
2. **题目预览页**：生成题目后预览排版效果
3. **导出页**：Word导出、下载、打印操作

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 版本选择器 | 顶部下拉切换学前版、人教版一年级(上/下)、二年级(上/下) |
| 首页 | 知识点列表 | 每个版本按知识点分类展示，可折叠/展开 |
| 首页 | 知识点卡片 | 包含知识点名称、例题展示、题目数量调整器(默认10题，1-100)、打印答案选项、开始练习按钮 |
| 预览页 | 题目预览 | 上半部分显示生成的题目排版效果 |
| 预览页 | 操作按钮 | 导出Word、重新生成按钮 |
| 导出页 | 文件操作 | 下载、分享、打印入口 |

---

## 3. 核心流程

```
用户选择版本 → 选择知识点 → 设置题目数量 → 点击开始练习
    ↓
系统生成随机题目 → 进入预览页 → 预览排版效果
    ↓
点击导出Word → 生成.docx文件 → 下载/打印/分享
```

## 5. 生成规则

### 5.1 随机生成规则
- 题目不重复、不超纲，严格匹配知识点范围
- 控制结果范围：如20以内加法，结果≤20；有余数除法，余数＜除数
- 比大小题：随机生成两个数字，搭配> / < / =三种符号

### 5.2 格式输出
- 横式排版：`10÷2=____`、`18○9`

### 5.3 竖式格式
- 自动生成标准竖式格式，带答题横线和计算区
- 答案页显示完整竖式计算过程（含进位/退位标记）

---

## 6. Word导出规格

- **格式**：.docx格式，兼容Word/WPS
- **页面设置**：默认A4纸
- **口算题排版**：横向4列，每页约32题，字体14号宋体
- **竖式题排版**：纵向2列，每页约20题，字体16号宋体
- **页眉**：可选「XX年级XX练习卷」
- **页脚**：显示页码
- **双页模式**：勾选「打印答案」后，第1页为空白练习卷，第2页为参考答案

## 7. UI设计

### 7.1 设计风格
- **主题**：友好、活泼、适合儿童
- **主色调**：蓝色(#4A90E2)为主，橙色(#F5A623)为辅
- **按钮风格**：圆角按钮，蓝色主按钮
- **字体**：使用圆润易读的字体
- **布局**：卡片式布局，清晰直观
- **图标**：使用emoji和简单图标增加趣味性

### 7.2 页面设计

| 页面 | 模块 | UI元素 |
|-----|------|-------|
| 首页 | 顶部版本选择器 | 下拉菜单，显示当前版本 |
| 首页 | 知识点卡片 | 白色卡片，圆角，阴影效果 |
| 首页 | 数量调整器 | 加减按钮+数字显示 |
| 首页 | 主按钮 | 蓝色背景，白色文字，圆角 |
| 预览页 | 题目展示区 | 白色背景，模拟纸张效果 |
| 预览页 | 操作区 | 导出、重新生成按钮 |

### 7.3 响应式设计
- 桌面端优先设计
- 平板和移动端自适应布局
- 打印预览使用A4纸张比例
